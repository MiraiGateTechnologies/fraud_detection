Q1. Jis user ko model ne fraud bola aur agent ne NOT FRAUD bola, wahi user baad me nayi withdrawal request le ke dobara aaye, to kya model use phir se fraud bolega?

Ans - Haan bol sakta hai. Nayi request ka fraud % us user ke naye data se phir se banta hai, aur agent ke pichhle GENUINE se ussey chhoot nahi milti.
