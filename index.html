Account groups

A group is 3 or more users under the same master who show similar unusual behaviour within 72 hours. A group can point to organised fraud. The colour strip shows the group's median fraud %. Select “View requests” to open the group's withdrawal requests.

How the model was tested

AUC runs from 0.5 (no better than chance) to 1.0 (perfect). “At 1% false alarms” means the score is set so that it flags 1% of genuine requests, and the column shows how many fraud cases it catches at that setting.

What raises the score

Losses and low activity never raise the score. The direction of each factor is fixed in advance, so the model cannot learn a wrong direction from a small number of fraud examples.

Known pattern score and fraud %

The final fraud % is the higher of two numbers: the known-pattern score shown here, and the behaviour score. An older account needs a stronger pattern match for the same %.

How to read the fraud %

What the score means. The fraud % shows how closely a request or a user matches confirmed fraud cases. 90% or more means it looks more like fraud than 999 of every 1,000 approved requests. Confirmed fraud cases are always shown at 95% or more. It is not the chance that the user is a fraudster.

The decision stays with the agent. The score shows which requests to check first, and why. It does not hold or reject any withdrawal.

Confirmed fraud ticks belong to the player. Ticking a user marks every request from that user, in both sections. Ticks are saved to a shared database, so every reviewer sees the same list.
